# 0.2.2 — Open to everyone

**Status:** Dev  
**Theme:** Published images and the hardening a public release needs.

## Running it

- The image is now published to GitHub Container Registry for amd64 and arm64: `ghcr.io/zypher-systems/journal`. `:latest` is the newest release; versions are tagged (`:0.2.2`, `:0.2`) and `:dev` follows unreleased work.
- `docker-compose.yml` runs the published image. To build from a checkout instead, add `docker-compose.build.yml` (see the README).
- `POSTGRES_PASSWORD` is now required; compose stops with a clear message if it's missing. Existing installs already have one in `.env`. If yours relied on the old default, set `POSTGRES_PASSWORD=journal` to keep it working, then change it inside Postgres and in `.env` together.
- Sign-in forms are only accepted from `ORIGIN`. The fixed `localhost`/`127.0.0.1` ports are no longer trusted, so browse at the exact address in `ORIGIN`.
- The development database listens on `127.0.0.1` only.

## Security

- Sign-in is throttled: five failures for an account, or fifty from one address, pause sign-in for up to 15 minutes. Behind a proxy, set `ADDRESS_HEADER=X-Forwarded-For`.
- After sign-in, only same-site redirects are followed (`?redirectTo=//elsewhere` goes home instead).
- Changing your password signs out your other sessions. Sign-out takes a POST, so a link from another site can't sign you out.
- Search snippets are escaped: an entry that mentions HTML shows it as text instead of rendering it.
- Pages can't be framed by other sites, and responses carry `nosniff` and a same-origin referrer policy.
- sharp 0.35, for the libvips/libheif advisories on the photo upload path.

## Fixes

- A tag with a literal `%` in its name no longer errors.
- A malformed timeline cursor is ignored instead of erroring.
- The health check now includes the database, so the container reports unhealthy when Postgres is down.
- Postgres notices no longer fill the app log.
- The README's HTTPS example now runs.

## Known

- Tiptap 2 carries a moderate advisory that only Tiptap 3 fixes. Each person only ever sees their own entries, which limits the impact; the move to Tiptap 3 is planned for 0.4.0.
