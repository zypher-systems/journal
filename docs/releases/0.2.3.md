# 0.2.3 — Quieter upkeep

**Status:** Release  
**Theme:** Routine dependency updates, and fewer automated pull requests.

## Updates

- svelte 5.57.1, vite 8.3.1, @sveltejs/vite-plugin-svelte 7.3.1
- drizzle-orm 0.45.3, drizzle-kit 0.31.11
- @node-rs/argon2 2.2.1, jszip 3.10.2

## Upkeep

- Dependabot proposes only minor and patch updates, grouped into one pull request per ecosystem. Major versions such as Tiptap 3 are planned upgrades on the roadmap.
- Dependabot security alerts stay on. Security-fix pull requests are off, because they always target `main`; fixes ship in patch releases like any other change.
