# 0.2.1 — Admin boundary (critical)

**Status:** Release  
**Critical:** upgrade right away.

## What's fixed

- The admin actions (create account, deactivate/reactivate, reset password) now refuse anyone who isn't an admin. Before this, any signed-in member could call them directly, which let a member reset another person's password and read their journal, or create an admin account.
- An admin password reset now signs that account out everywhere.
- The smoke test covers both: a member is refused each admin action, and a reset ends the member's sessions.

## After upgrading

Check the People page for accounts you didn't create, and for admins who shouldn't be. Reset the password of anyone you're unsure about.
