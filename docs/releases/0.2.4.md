# 0.2.4 — Less machinery

**Status:** Release  
**Theme:** Fewer automated pull requests and CI runs; a release ships the exact image that was tested.

## Releases

- A release tag no longer rebuilds the image. It promotes the image that was built and smoke-tested on `dev` (`:sha-xxxxxxx`) to `:X.Y.Z`, `:X.Y` and `:latest`, after checking the tag matches `package.json`. The image's version label is set from `package.json` when it's built, so the promoted image already says its version.
- Pushes to `main` no longer run CI: `main` only takes commits that already passed on `dev` or a hotfix branch. The `:main` image tag is no longer updated.
- Hotfix branches publish their image by commit, so a hotfix release has an image to promote.

## Upkeep

- Dependabot no longer opens update pull requests. Security alerts stay on; dependency updates and advisories are handled in patch releases.
